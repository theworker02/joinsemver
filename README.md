# joinsemver

Join validation gates for semver inputs before they hit prod.

**Site:** https://theworker02.github.io/joinsemver/

## Install / run

```bash
git clone https://github.com/theworker02/joinsemver.git
cd joinsemver
node src/cli.js
node --test
```
